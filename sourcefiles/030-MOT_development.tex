\chapter{НАУЧНО-ИССЛЕДОВАТЕЛЬСКАЯ ЧАСТЬ}

Настоящая глава содержит формальную постановку задачи мультиобъектного отслеживания, выбор архитектурных решений и объединение выбранных технологий, которые в результате предоставят систему мультиобъектного отслеживания, которая удовлетворяет поставленному техническому заданию. 

Первым делом ставится формальная задача для МОТ, определяются входные данные, которые поступают на систему, описывается логика работы. Далее производится выбор конкретного детектора из семейства YOLO, которое было выбрано по результатам части~\ref{subsec:detector}. Также остановимся на выборе набора данных, который является важной частью системы. Затем проведем анализ алгоритма отслеживания DeepSORT, оценим основные показатели при использовании стандартного детектора и фильтра предсказания. Проведем сравнение стандартного фильтра с выбранным и реализуем интеграцию последнего.

На основе полученных результатов разработаем систему МОТ с использованием нелинейного фильтра предсказания и современного детектора, обученного специально для автономных ТС.
