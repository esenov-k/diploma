\section{Алгоритм DeepSORT}

Как было описано в части~\ref{subsec:mot_algotithms}, наиболее подходящим алгоритмом МОТ, теперь разберем его более подробно.

DeepSORT (Simple Online and Realtime Tracking with Deep Association) — это усовершенствованный метод мультиобъектного отслеживания, который сочетает алгоритм детекции объектов и алгоритм слежения, используя признаки объектов для повышения устойчивости отслеживания~\cite{abellai2024object}~\cite{bewley2016simple}. Основная цель DeepSORT — улучшение точности сопоставления объектов в последовательностях кадров видео. Алгоритм работает на основе фильтра Калмана для предсказания будущих состояний треков, а также использует венгерский алгоритм (Hungarian Algorithm)~\cite{kuhn1955hungarian} для сопоставления треков и новых детекций. Кроме того, в DeepSORT интегрированы визуальные признаки, которые извлекаются с помощью глубокой нейронной сети (обычно ResNet). Эти признаки позволяют учитывать не только пространственное положение объектов, но и их визуальные характеристики.

На рисунке~\ref{fig::deepsort_algorithm} представлена блок-схема алгоритма работы DeepSORT и пояснение к каждому из этапов~\cite{IkomiaDeepSort2023}:

\img[htb]{fig::deepsort_algorithm}{deepsort_algorithm.png}{Блок-схема алгоритма DeepSORT}{1}

\begin{enumerate}
    \item Обнаружение объектов:
    \begin{itemize}
        \item Производится определение класса объекта при помощи выбранного детектора (YOLO11n), который определяет ограничивающие рамки.
        \item Для каждого обнаруженного объекта производится извлечение признаков, таких как пространственные характеристики и описания на основе сверточной нейронной сети (ResNet).
    \end{itemize} 
    \item \label{item::KF} Предсказание состояния с использованием Фильтра Калмана (расширенного фильтра Калмана).
    \item Ассоциация треков: венгерский алгоритм сопоставляет треки на основе матрицы стоимости, которые учитввают расстояние Махаланобиса и косинусное расстояние для углубленного описания внешнего вида.
    \item Обновление треков: обновление положения треков и их состояния на основе фильтра Калмана (пункт~\ref{item::KF}).
    \item Инициализация и завершение треков: новые треки создаются для неассоциированных детекций, но если они не обновлялись заданное количество кадров, то треки завершаются.
\end{enumerate}

Перейдем к математическому описанию алгоритма DeepSORT.

Пусть ${d}(i,j)$ — метрика расстояния между треком $i$ и детекцией $j$, вычисляемая как взвешенная сумма евклидова расстояния между признаками и расстояния Махаланобиса между позициями:

\begin{equation}
    \begin{aligned}
        {d}(i, j) = \alpha*{d}_{\text{appearance}}(i, j) + (1 - \alpha)*{d}_{\text{position}}(i, j),
    \end{aligned}
\end{equation}

где ${d}_{\text{appearance}}(i, j)$ — расстояние между признаками объектов, ${d}_{\text{position}}(i, j)$ — расстояние Махаланобиса между позициями.

Для сопоставления треков и детекций используется минимизация общей стоимости сопоставления с помощью венгерского алгоритма:

\begin{equation}
    \begin{aligned}
        \min \sum_{i, j} c(i, j) x_{i,j},
    \end{aligned}
\end{equation}

где $c(i, j)$ — стоимость сопоставления пары трек-детекция, $x_{i,j}$ — бинарная переменная, равная 1, если трек $i$ сопоставлен с детекцией $j$, и 0 — иначе.

Теперь перейдем к коррекции состояния. Текущее состояние трека обновляется по формуле:

\begin{equation}
    \begin{aligned}
        {x}_k = {x}_k + {K}_k ({z}_k - {H} {x}_k),
    \end{aligned}
\end{equation}

где ${K}_k$ — матрица Калмана, ${z}_k$ — вектор измерений, ${H}$ — матрица измерений.

Обновление ковариации ошибок происходит таким образом:

\begin{equation}
    \begin{aligned}
        {P}_k = ({I} - {K}_k {H}) {P}_k,
    \end{aligned}
\end{equation}

где ${P}_k$ — ковариционная матрица ошибок.

Из особенностей данного алгоритма, можно выделить высокую устойчивость к перекрытиям, которая достигается за счет использования внешнего вида объекта. Благодаря использованию фильтра Камлана при обновлении состояния треков, повышается точность. При этом модель спокойно работает в реальном времени благодаря современному детектору объектов, скорость которого высока и полностью удовлетворяет нашим требованиям.

Для обновления трека необходимо сопоставлять его с детекциями, но если трек не обновляется в течение нескольких кадров, он удаляется. Новые детекции, не сопоставленные с существующими треками, инициируют новые треки.

Таким образом, алгоритм DeepSORT обеспечивает точное и устойчивое слежение за объектами даже при сложных дорожных ситуациях, включая резкие перестроения и временные пропадания объектов из поля зрения, однако использования стандартного фильтра Калмана не учитывает нелинейности, которые необходимо учитывать в условиях сложных дорожных ситуациях и плотных потоках.

\subsection{Отличия и преимущества расширенного фильтра Калмана перед обычным фильтром Калмана}

Расширенный фильтр Калмана (EKF) является развитием стандартного фильтра Калмана (KF) и предназначен для работы с нелинейными системами. Первым, и, наверное одним из самых важных отличий является учет нелинейностей системы. Обычный фильтр Калмана применим только для линейных систем, где динамика описывается линейными уравнениями. EKF расширяет область применения фильтра за счет использования нелинейных функций перехода состояния $f(\cdot)$ и измерений $h(\cdot)$. Это достигается путем линеаризации функций с помощью Якобианов на каждом временном шаге.

EKF аппроксимирует нелинейные функции в окрестности текущего состояния с помощью первых производных. Якобиан функции перехода состояния $f(\cdot)$ используется для предсказания ковариации, а Якобиан функции измерений $h(\cdot)$ — для корректировки состояния:

\begin{equation}
    {F}_t = \frac{\partial f}{\partial {s}} \big|_{{s}_{t-1}}, \quad {H}_t = \frac{\partial h}{\partial {s}} \big|_{{s}_t^-}.
\end{equation}

Эти матрицы позволяют учитывать нелинейное поведение системы, что улучшает точность предсказаний.

Исходя из вышесказанного, можно выделить ряд преимуществ EKF перед KF:

\begin{itemize}

    \item EKF применим в задачах с нелинейной динамикой, таких как трекинг объектов с ускорением, изменение направления движения и работа с углами (например, ориентация робота).

    \item Обеспечивает более точное предсказание и обновление состояния для систем, где линейные модели недостаточны.

    \item Позволяет интегрировать сложные модели измерений, такие как данные от сенсоров, работающих с углами или расстояниями.

\end{itemize}

Стоит также упомянуть и ограничения, с которыми обычно сталкиваются при замене стандартного KF на EKF. Из-за того, что EKF 
требует вычисления Якобианов, увеличивается вычислительная сложность по сравнению с KF. Однако для современных вычислительных устроиств прирост сложности не является критичным, о чем свидетельствует~\cite{ponticelli2024comparison}.

Линеаризация вводит ошибки аппроксимации, особенно в системах с высокой степенью нелинейности.

Зависимость от корректной математической модели системы: ошибки в определении $f(\cdot)$ и $h(\cdot)$ могут привести к значительным погрешностям.



\subsection{Методология интеграции EKF в DeepSORT}

Интеграция расширенного фильтра Калмана (EKF) в алгоритм DeepSORT требует замены стандартного фильтра Калмана на EKF, что улучшает возможности отслеживания за счет учета нелинейностей в движении объектов~\cite{bewley2016simple}.

Первым делом произведем замену линейного фильтра Калмана на расширенный. На этапе предсказания и обновления состояния стандартный линейный фильтр Калмана заменяется EKF. Это требует определения:

\begin{itemize}

    \item Нелинейной функции перехода состояния $f(\cdot)$, которая описывает динамику объекта.

    \item Нелинейной функции измерений $h(\cdot)$, связывающей состояние объекта с наблюдениями.

    \item Якобианов ${F}_t$ и ${H}_t$, необходимых для линеаризации функций $f(\cdot)$ и $h(\cdot)$.

\end{itemize}

Далее необходимо расширить модуль предсказания. Для предугадывания будущего состояния и ковариации в DeepSORT используются нелинейные уравнения EKF:

\begin{equation}
{s}_t^- = f({s}_{t-1}), \quad {P}_t^- = {F}_t {P}_{t-1} {F}_t^T + {Q}.
\end{equation}

Следующий шаг заключается в адаптации этапа обновления состояния. Оно в EKF осуществляется с учетом измерений. В DeepSORT это реализуется через:

\begin{equation}
{K}_t = {P}_t^- {H}_t^T ({H}_t {P}_t^- {H}_t^T + {R})^{-1},
\end{equation}

\begin{equation}
{s}_t = {s}_t^- + {K}_t ({z}_t - h({s}_t^-)), \quad {P}_t = ({I} - {K}_t {H}_t) {P}_t^-.
\end{equation}

Затем необходимо учитывать визуальные признаки. DeepSORT использует их для улучшения сопоставления треков и детекций. EKF интегрируется таким образом, чтобы комбинировать предсказания положения объектов с результатами анализа визуальных признаков, сохраняя их значимость в процессе отслеживания.

После интеграции EKF проводится тестирование алгоритма на наборах данных, таких как MOTChallenge, для оценки качества отслеживания.
