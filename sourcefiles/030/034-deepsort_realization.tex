\section{Программная реализация алгоритма DeepSORT с использованием расширенного фильтра Калмана}

Программа реализует алгоритм DeepSort, который предназначен для отслеживания объектов в видео или потоке изображений с использованием метода глубокого обучения для извлечения признаков и метрики ближайшего соседа для сопоставления между кадрами~\cite{Sun2006}. Основной задачей алгоритма является связывание объектов между последовательными кадрами, обеспечивая корректное и стабильное их отслеживание в реальном времени.

\subsection{Используемые программные компоненты}

Класс \lstinline:DeepSort:, предназначенный для отслеживания объектов в реальном времени, включает в себя следующие нестандартные модули:  \lstinline:Extractor:, \lstinline:NearestNeighborDistanceMetric:, \lstinline:Detection: и \lstinline:Tracker:. 

\textbf{\lstinline:Extractor:} -- модуль для извлечения признаков объектов из их изображений с использованием заранее обученной нейросети.

\textbf{\lstinline:NearestNeighborDistanceMetric:} -- реализует метрику косинусного расстояния для сопоставления объектов по визуальным признакам.

\textbf{\lstinline:Detection:} --  класс, который представляет детекцию объекта, включая его координаты, уровень уверенности и признаки.

\textbf{\lstinline:Tracker:} -- управляет состояниями треков (инициализация новых треков, предсказание их положения и обновление). Данный модуль представляет наибольший интерес, так как в нем мы реализуем расширенный фильтр Калмана, благодаря которому алгоритм по отслеживанию объектов получает возможность работать с нелинейными состояниями окружающих ТС.

\subsection{Алгоритм работы программы DeepSORT}

Алгоритм работы программы \textbf{DeepSORT} начинается с инициализации, где задаются ключевые параметры, необходимые для корректного отслеживания объектов. В их числе: \lstinline:model_path: (путь к модели для извлечения признаков), \lstinline:max_dist: (максимально допустимое косинусное расстояние между признаками объектов), \lstinline:min_confidence: (порог уверенности детекции, ниже которого объекты игнорируются), \lstinline:nms_max_overlap: (порог для подавления перекрывающихся объектов), \lstinline:max_age: (сколько кадров объект может отсутствовать перед удалением трека), \lstinline:nn_budget: (лимит на количество сохраненных признаков для сопоставления) и \lstinline:use_cuda: (использование GPU для ускорения работы).

После инициализации программа переходит к этапу обновления трекера через метод \lstinline:update:. При каждом новом кадре извлекаются признаки объектов из изображений с помощью нейросети (\lstinline:_get_features:), преобразуются координаты объектов из формата центра и размеров (\lstinline:bbox_xywh:) в формат верхнего левого угла (\lstinline:bbox_tlwh:), а затем генерируются объекты детекций (\lstinline:Detection:), которые включают в себя координаты, уровень уверенности и признаки каждого объекта.

Затем трекер обновляется следующим образом: сначала выполняется предсказание новых положений активных треков на основе предыдущих данных (\lstinline:self.tracker.predict():), после чего выполняется обновление треков с учетом новых детекций (\lstinline:self.tracker.update(detections):). На завершающем этапе формируются выходные данные, включающие координаты объектов, идентификаторы треков (\lstinline:track_id:) и идентификаторы объектов (\lstinline:track_oid:). Эти данные собираются и возвращаются для дальнейшего использования.

Ключевые методы программы обеспечивают работу с координатами и признаками объектов. Метод \lstinline:_xywh_to_tlwh: преобразует координаты объектов из формата центра и размеров в формат верхнего левого угла и размеров. Метод \lstinline:_get_features: отвечает за извлечение визуальных признаков из изображений объектов с использованием обученной модели. Метод \lstinline:increment_ages: увеличивает возраст треков в тех случаях, когда они не были обновлены в текущем кадре, что позволяет управлять удалением устаревших треков. Методы \lstinline:_tlwh_to_xyxy: и \lstinline:_xyxy_to_tlwh: занимаются преобразованием координат между форматами верхнего угла и пар углов ограничивающего прямоугольника.

\subsection{Класс Tracker}

Алгоритм работы класса \textbf{Tracker} начинается с инициализации, где задаются ключевые параметры, необходимые для отслеживания объектов и управления их состояниями. В их числе: \lstinline:metric: (метрика расстояния для сопоставления объектов), \lstinline:max_iou_distance: (максимальная допустимая IOU-дистанция при сопоставлении), \lstinline:max_age: (максимальное количество кадров, в которых объект может отсутствовать перед удалением трека) и \lstinline:n_init: (количество кадров, необходимых для подтверждения нового трека).

После инициализации создается расширенный фильтр Калмана (\lstinline:extended_kalman_filter.ExtendedKalmanFilter:), который используется для предсказания и обновления положений объектов. В списке \lstinline:self.tracks: хранятся активные треки, а \lstinline:self._next_id: используется для генерации уникальных идентификаторов треков.

На каждом новом кадре вызывается метод \lstinline:predict:, который обновляет предполагаемые позиции объектов с использованием расширенного фильтра Калмана. Метод \lstinline:increment_ages: увеличивает возраст каждого трека и помечает его как пропущенный, если на текущем кадре не удалось найти соответствие.

Основное обновление треков выполняется методом \lstinline:update:. Сначала выполняется сопоставление текущих детекций с треками через метод \lstinline:_match:, который делит треки на подтвержденные и неподтвержденные, а затем использует комбинацию признаков и IOU для поиска соответствий. Треки, которым удалось найти соответствия, обновляются с помощью расширенного фильтра Калмана, пропущенные треки помечаются, а для новых детекций создаются новые треки методом \lstinline:_initiate_track:. В конце старые или устаревшие треки удаляются.

Метод \lstinline:_match: делит процесс сопоставления на два этапа: сначала выполняется сопоставление подтвержденных треков с помощью метрики признаков (\lstinline:gated_metric:), а затем оставшиеся треки сопоставляются по IOU. Это гарантирует, что треки остаются активными даже в случае временного отсутствия детекции.

Ключевые методы программы:
\begin{itemize}
    \item \lstinline:predict: — предсказывает новые положения объектов на основе  расширенного фильтра Калмана.
    \item \lstinline:increment_ages: — увеличивает возраст треков и помечает пропущенные.
    \item \lstinline:update: — обновляет треки на основе текущих детекций.
    \item \lstinline:_match: — выполняет сопоставление детекций с треками.
    \item \lstinline:_initiate_track: — создает новый трек для объекта, если он не нашел соответствия среди существующих.
\end{itemize}
