\section{Алгоритм поиска наиболее важного объекта (НВО)}

Работа систем безопасности ИСПВ в основном связанна с выделением наиболее <<интересных>> для системы объектов, которые могут в той или иной степени представлять опасность для водителя и пассажиров. В качестве системы по определению таких объектов, была разработана система по поиску наиболее важного объекта (НВО).

Алгоритм по определению НВО представлен на рисунке~\ref{fig:mio}

Функция фильтрует объекты на основе их скорости и положения, исключая статические объекты и объекты, движущиеся навстречу, а также объекты, находящиеся вне заданных зон~\cite{Ziegler2014}.

\subsection{Программная реализация алгоритма по поиску НВО}

В качестве входных параметров функция принимает три аргумента:

Первым аргументом является выходная шину данных НВО (изначально пустая). Она содержит количество обнаруженных НВО и массив структур, каждая из которых описывает характеристики объекта: индекс объекта, координата по оси X, координата по оси Y,скорость по оси X, и скорость по оси Y.

Вторым аргументом идут данные всех объектов, обнаруженных радаром и алгоритмом DeepSORT~\cite{Feng_2021}. Она включает массив детекций, каждая из которых содержит поля, аналогичные первому аргументу.

Последним идут данные из CAN-шины транспортного средства. Она включает поле скорости нашего транспортного средства.

Функция возвращает структуру, которая содержит данные о наиболее опасных объектах (MIO). Структура включает количество обнаруженных MIO и массив структур детекций, каждая из которых описывает характеристики объекта: индекс объекта, координата по оси X, координата по оси Y,скорость по оси X, и скорость по оси Y.

\textbf{Алгоритм работы:}

\begin{enumerate}

    \item Инициализация:

    \begin{itemize}

        \item Создается массив \lstinline:MIO_index: для хранения индексов наиболее важных объектов.

        \item Инициализируется счетчик \lstinline:NumMIO: для подсчета количества НВО.

    \end{itemize}

    \item Фильтрация объектов

    Для каждого объекта, обнаруженного радаром и алгоритмом DeepSORT, проверяется:

    \begin{itemize}

        \item Наличие объекта, то есть его индекс не равен 0;
        
        \item Относительная скорость объекта;

        \item Положение объекта в заданных зонах (левый, правый и продольный коридоры).

    \end{itemize}

    Объекты, которые двигаются навстречу, которые имеют скорость ниже порога и которые находятся вне заданных зон исключаются из рассмотрения.

    \item Определение НВО:

    \begin{itemize}

        \item Если объект удовлетворяет всем условиям (находится в заданных зонах и не исключен), он добавляется в список НВО;

        \item Индекс объекта сохраняется;

        \item Увеличивается счетчик.

    \end{itemize}

    \item Формирование выходной структуры:

    \begin{itemize}

        \item В выходную структуру записываются данные о каждом объекте, включая его индекс, координаты и скорость

        \item Также, записывается общее количество НВО.

    \end{itemize}

\end{enumerate}

\textbf{Калибровочные параметры}

Программа использует глобальные калибровочные параметры, которые определяют границы зон и пороговые значения:

\begin{itemize}

    \item Границы левой зоны по оси Y;

    \item Границы правой зоны по оси Y;

    \item Границы продольной зоны по оси X;

    \item Порог скорости для исключения статических объектов;

    \item Порог относительной скорости для исключения статических объектов.

\end{itemize}

Так как алгоритм представляет из себя универсальную функцию, калибровочные параметры задаются под конкретное ТС и сферу его применения.

\subsection{Связь алгоритма поиска НВО с DeepSORT}

Алгоритм поиска наиболее важного объекта (НВО) напрямую использует данные, предоставляемые алгоритмом DeepSORT, который отслеживает объекты на основе их положения, скорости и визуальных признаков, обеспечивая непрерывное обновление треков в реальном времени. Алгоритм НВО анализирует информацию, полученную после алгоритма отслеживания и данных с радаров, затем выделяет объекты, представляющие наибольшую угрозу или важность для безопасности движения.
